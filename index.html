El Descubrimiento

Videos cortos sobre el origen de las cosas: cómo la humanidad encontró el carbón, el uranio o el fuego, y cómo se inventaron la pólvora, la imprenta y mucho más.

Sobre esta aplicación

Este sitio corresponde a la herramienta interna que usa el canal para publicar sus propios videos en YouTube mediante la API de YouTube Data. La aplicación solo sube contenido al canal de su propietario y no recopila datos de otros usuarios.
