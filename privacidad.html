Política de privacidad

Última actualización: 12 de octubre de 2026

1. Qué es esta aplicación

"El Descubrimiento" es una herramienta de uso personal que utiliza la API de YouTube Data para subir y administrar videos en el canal de YouTube de su propietario. No está destinada al uso del público general.

2. Datos a los que accede

Al autorizar la aplicación con una cuenta de Google, esta obtiene permiso para:

  • Subir videos al canal de YouTube asociado a esa cuenta.
  • Editar los datos de esos videos (título, descripción, etiquetas, miniatura y listas de reproducción).

La aplicación no lee correos, contactos ni ningún otro dato de la cuenta de Google.

3. Cómo se usan y guardan los datos

Los tokens de acceso que entrega Google se guardan únicamente en el equipo del propietario, para poder subir videos de forma automática. No se envían a terceros, no se venden y no se usan con fines publicitarios.

4. Uso de los Servicios de API de YouTube

Esta aplicación utiliza los Servicios de API de YouTube. Al usarla, aceptás las Condiciones del Servicio de YouTube. También se aplica la Política de Privacidad de Google.

5. Cómo revocar el acceso

Podés quitarle el acceso a la aplicación en cualquier momento desde la página de permisos de tu cuenta de Google. Al hacerlo, los tokens guardados dejan de funcionar.

6. Contacto

Para cualquier consulta sobre esta política, escribí a descubrimientoyt@gmail.com.
